# HFGP ゲーム用ボート・レーサーアセット v1.0

既存のリプレイ用ボートと男女レーサーを、6艇を同時に描画するゲーム向けに軽量化したアセットです。イベント・宣伝アニメ用キャラクターとは別パッケージです。

## まず確認する

1. ZIPをすべて展開してください。
2. Windowsでは `Preview_Windows.bat` を起動します。Python 3が必要です。Blender・FFmpegは不要です。
3. ブラウザーに6艇が表示されます。「品質」と「モデルの詳細度」で両版・全LODを切り替えられます。ドラッグで視点回転、ホイールで拡大縮小できます。
4. 閉じるときはサーバーのウィンドウで Ctrl+C を押します。

`index.html` の直接ダブルクリックではGLBの読み込みが制限されます。同梱サーバーは自分のPCの127.0.0.1だけで動き、外部へのアップロードはしません。他のOSでは `python3 serve_preview.py` を実行してください。Windowsの `py` がない場合は `python serve_preview.py` でも起動できます。

確認画面はアセットの姿勢・描画確認用です。水面は仮の平面で、レースの物理や本体プログラムは含みません。

## 出力内容

| フォルダー | 内容 |
|---|---|
| `mobile/` | ミドルレンジスマホを想定したボート・男性・女性、各3段階LOD |
| `pc1080ti/` | GTX 1080 Tiを想定した同構成 |
| `textures/` | 艇番1～6の番号、選手のゼッケン、交換用艇体テクスチャー |
| `runtime/` | Three.js用の6艇複製・色変更・身長・操縦姿勢・ゲーム座標接続コード |
| `viewer/` | ローカルで動く確認画面とThree.js r180（MITライセンス同梱） |
| `source/` | 元のBlenderマスターから再生成するスクリプト |
| `reports/` | 実際の形状数、GLB形式検証、WebGL動作検証結果 |

形式は **glTF 2.0のGLB**。画像はGLB内にも埋め込んであります。Dracoなどの追加デコーダーは不要です。ボートとレーサーは独立し、男女を交換できます。レーサーは20ボーン、頂点あたり最大4ウェイトです。

## モデルの負荷

表の「1組」はボート＋選手1人です。三角形数は書き出した実データから集計しました。LOD0が最も細かく、LOD2が遠景向けです。

| 対象 | LOD | ボート | 選手 | 1組 | 6組 |
|---|---:|---:|---:|---:|---:|
| スマホ | 0 | 5,000 | 2,997 | 7,997 | 47,982 |
| スマホ | 1 | 2,179 | 1,383 | 3,562 | 21,372 |
| スマホ | 2 | 1,225 | 男1,017／女1,035 | 男2,242／女2,260 | 13,470※ |
| PC | 0 | 14,000 | 8,999 | 22,999 | 137,994 |
| PC | 1 | 6,498 | 4,200 | 10,698 | 64,188 |
| PC | 2 | 2,480 | 1,584 | 4,064 | 24,384 |

※男性5人＋女性1人の場合。ボート＋選手のベース描画はスマホ版8呼び出し/組、PC版9呼び出し/組。6組で48／54です。影・追加パス・水面・背景・UIは別に加算されます。

艇体テクスチャーはスマホ512角、PC1024角。艇番画像は128角です。細かな部品を統合し、固定色は頂点カラーへ焼き込んでいます。スマホ版は小部品の省略が多く、プロペラはモーターに統合されています。PC版はプロペラを別ノードとして回せます。ハンドル・スロットルの独立可動は両版とも省略しています。

## 実ゲームへの組み込み

詳しくは `INTEGRATION_日本語.md` を参照してください。まず `boat_lod0.glb` と `racer_male_lod0.glb` または `racer_female_lod0.glb` を読み込みます。選手は艇体の `RacerMount` に置きます。

Three.jsでは同梱 `loadAssetSet()` を使うと、スキニングを独立させた6艇を作成できます。ボートの位置・旋回・傾き・舳先角は本体が決めた結果を渡します。アセット側でゲームの物理を再計算しません。

GLBには `Cruise` / `TurnLeft` / `TurnRight` / `BowUp` の姿勢クリップを付属しています。これらは各1秒の固定姿勢です。連続的な走行アニメーションや口・表情アニメーションではありません。Three.js用コードでは骨格を直接制御して、体格と姿勢が変わっても手を操縦位置に合わせます。Unity・GodotなどではGLBをインポートしたうえで、この制御をエンジン側のIKに移植するか、付属姿勢をブレンドしてください。エンジン固有のPrefabやシーンは含みません。

## 確認済みの範囲

- 18個すべてのGLBをKhronos glTF Validatorで検証：エラー0、警告0。
- ChromiumのWebGLで男女・6艇・艇番色・各LODを読み込んで表示。
- 個別骨格、操縦姿勢、手の位置合わせ、描画数を確認。身長140～200cmを含む1,944姿勢で非数値変形なし、グリップ誤差は最大0.001mm未満。数値は同梱レポートに記録。

**実際のスマホ、GTX 1080 Ti、ゲーム本体上でのFPS測定は未実施です。** ここでの「対象」はアセットの負荷設計です。確認環境はソフトウェアWebGLで、確認画面のFPSは実機の性能目安には使えません。

スマホ側は、まず影を無効にした俯瞰表示・簡易水面から組み込み、端末で描画時間を測ってLODや解像度を調整してください。PC側も水面反射、飛沫、影、背景を加えた状態で測定が必要です。完全なゲームのフレームレートをこのアセットだけで保証するものではありません。

## 再生成

通常の利用では不要です。Blender 4.5と元の `HFGP_replay_assets` の `01_boat`・`02_racers` が必要です。容量を抑えるため、元の高詳細マスターはこのZIPには重複収録していません。

```text
blender -b --python source/build_assets.py -- /path/to/HFGP_replay_assets
```

`build_assets.py` が変更するのはこのパッケージ内のGLB・生成画像・形状数レポートです。ゲーム本体とイベント用モデルは変更しません。
