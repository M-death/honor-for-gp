# BGMの差し替え方

> 2026-10-31：いまはBGMを使わないので、mp3はゲームから外して `bgm_archive/`（プロジェクトの一番上）に保管しています。使うときは mp3 を bgm/ に戻して `"enabled": true`。

設定はすべて `bgm/bgm.json` にあります。プログラムを触らずに差し替えられます。

## 鳴らす／鳴らさない
- `"enabled": true` … 鳴る（設定画面に「BGM」「BGMの音量」が出る）
- `"enabled": false` … 鳴らない（設定画面の項目も隠れる）

## 曲ごとの項目
| 項目 | 意味 |
|---|---|
| file | bgm/ の中のファイル名（mp3） |
| loop | 曲が終わりそうになったら繰り返す範囲 [始まり秒, 終わり秒]。書かなければ繰り返さない（そのまま終わる） |
| startAt | レース曲だけ。スタート（スリット通過）が来る、ファイルの中の秒数 |
| from | レース曲だけ。ファイルのこの秒数より前は鳴らさない（頭の無音を飛ばす） |

## 曲と場面
| 名前 | 場面 | 曲の0秒 |
|---|---|---|
| menu | タイトル・メニュー・レース条件・節間・結果画面 | 自由（ループ） |
| race | ピット離れからのレース | ピット離れの合図。スタートは合図の100秒後なので、ふつうは startAt 100 |
| race2 | 枠なりのレース（待機行動なし） | レース開始はスタートの20秒前。startAt はふつう 20（頭に無音があればその分足す） |
| ta | タイムアタック・展示航走 | 自由（ループ） |
| goal | 自分のゴール、TAのゴール（1回だけ） | ゴールの瞬間 |

## 例：レース曲だけ差し替える
1. 新しい曲を `bgm/race_new.mp3` として置く
2. `"race": { "file": "race_new.mp3", "loop": [200, 230], "startAt": 100 }` に書き換える
3. `"enabled": true` にする

ループの秒数は小節の頭に合わせると継ぎ目が目立ちません（120BPMなら2秒ごと）。
